Hashfirst

Breach and password data from Have I Been Pwned. No API key, no account, no backend.
Hashed in your browser. Only the first 5 characters of the SHA-1 are sent.
Why this is safe. Your password is SHA-1 hashed by your own browser. Only a 5-character hash prefix goes to api.pwnedpasswords.com, which returns every hash sharing that prefix. The comparison happens locally. HIBP cannot tell which password you checked. This is the k-anonymity model, the scheme HIBP documents for exactly this purpose.

Email search is not here. That endpoint needs a paid API key and would mean sending your address to a server. Use haveibeenpwned.com directly for that — free.

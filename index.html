First 5 characters — sent Remaining 35 — never sent

Why this is safe to use

  1. Your password is SHA-1 hashed inside this browser tab.
  2. Only the first five characters of that hash are sent to api.pwnedpasswords.com.
  3. The API returns every hash beginning with those five characters — typically a few hundred.
  4. Your hash is matched against that list locally, so the answer never leaves your machine.

This is the k-anonymity model, the scheme Have I Been Pwned documents for exactly this purpose. The service cannot determine which password you checked. Requests also ask for padding, so the size of the response reveals nothing either.

Email search is not offered here. That endpoint requires a paid API key and would mean transmitting your address to a server. Search it free at haveibeenpwned.com.
